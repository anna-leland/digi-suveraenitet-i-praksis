# Digital suverænitet i praksis
### Specialeforberedende forløb hos OS2 2026 og specialesamarbejde i 2027

Dette repository dokumenterer mit forløb hos **OS2 – Offentligt digitaliseringsfællesskab** som en del af kandidatuddannelsen i Informationsvidenskab på Aarhus Universitet.

Arbejdet undersøger **digital suverænitet, open source-governance og selvevalueringer af OS2's produkter** med henblik på et efterfølgende specialesamarbejde med OS2 i foråret 2027.

## 🗂️ Repository og website

GitHub-repositoriet fungerer som den samlede dokumentation for projektet og indeholder både:

- arbejdsnoter og mødereferater
- interviewnoter
- planer og tidslinjer
- analyser og refleksioner
- bearbejdede resultater til offentliggørelse

Materialet skrives i Markdown og versionsstyres med Git.

**Ikke alt indhold på GitHub publiceres på websitet.** Udvalgte analyser, resultater og formidlede materialer publiceres gennem **GitHub Pages og Just the Docs**, mens fx rå interview- og mødenoter kun opbevares i repositoryet.

## 💼 Specialeforberedende forløb 2026

I efteråret 2026 arbejder jeg blandt andet med:

- analyse og facilitering af OS2's governance-selvevalueringer
- identifikation af problemområder, automatiseringspotentialer og kompetencebehov
- organisatoriske udfordringer ved open source-governance og digital suverænitet
- dokumentation og formidling af analyser og resultater

## 📚 Specialesamarbejde 2027

Det empiriske arbejde forventes at danne grundlag for et speciale om blandt andet:

- digital suverænitet
- open source-governance
- implementering af open source i den offentlige sektor
- Big Tech-afhængighed
- *Public Money, Public Code*
